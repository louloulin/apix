# APIX Gateway Simple Client

This is a simple web client that demonstrates how to use the APIX Gateway to interact with AI models.

## Features

- Chat interface for interacting with AI models
- Support for multiple AI models (OpenAI GPT, Anthropic Claude)
- Configurable gateway URL and API key
- Simple and clean UI

## Usage

1. Make sure the APIX Gateway is running
2. Open the `index.html` file in a web browser
3. Configure the gateway URL and API key in the settings section
4. Select the AI model you want to use
5. Type your message and click "Send" or press Enter

## Configuration

- **Gateway URL**: The URL of the APIX Gateway (default: `http://localhost:8080`)
- **API Key**: The API key to use for authentication (default: `test-key`)
- **Model**: The AI model to use (options: `gpt-3.5-turbo`, `gpt-4`, `claude-3-opus`)

## Notes

This is a simple client for demonstration purposes. In a production environment, you would want to:

- Add proper error handling
- Implement user authentication
- Add more features like conversation history
- Improve the UI/UX
